# Calculator

A polished, responsive Flutter calculator with a luxury dark-and-gold theme.

## Features

- Addition, subtraction, multiplication, division, percentage, sign toggle, decimal, clear, and backspace.
- Live expression and result display with operator precedence and floating-point-friendly formatting.
- Calculation history stored locally with `shared_preferences`.
- Persistent dark and light themes with a one-tap toggle.
- Gold ripple, hover, pressed, and haptic feedback on keypad controls.
- Responsive Material 3 layout, button feedback, and accessible control labels.

## Run

Install the Flutter SDK, then from this directory run:

```shell
flutter pub get
flutter run
```

For web or desktop, select a supported device, for example:

```shell
flutter run -d chrome
flutter run -d windows
```

Windows desktop builds with plugins require Developer Mode (or equivalent
symlink support) to be enabled in Windows settings.

Run the analyzer and tests with:

```shell
flutter analyze
flutter test
```
